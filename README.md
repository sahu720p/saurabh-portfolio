# Saurabh Kumar Sahu Portfolio

A modern, fast, and responsive personal developer portfolio built with Next.js, React, Tailwind CSS, and Framer Motion.

## 🚀 Live Demo
[http://localhost:3000](http://localhost:3000)

## ✨ Features
- Fully Responsive Design (Mobile, Tablet, Desktop)
- Ambient Dark Glassmorphism Theme
- Smooth Framer Motion Animations & Mouse Spotlight
- Tech Stack Categorized Filtering
- Projects Showcase with Expandable Cards & Links
- Interactive Contact Form & Social Links
- Resume PDF Integration

## 🛠 Tech Stack
- **Framework**: Next.js
- **Frontend**: React (JSX)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons & Lucide React

## ⚙️ Installation & Running

```bash
npm install
npm run dev
```
